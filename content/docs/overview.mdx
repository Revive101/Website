# Overview

Imlight is an independent private server project, entirely written in C# and developed by the Revive101 Team. This page what it is, what it isn't and what it can do today.

> [!IMPORTANT]
> Imlight is a framework for building a private server. It is not a finished game and it does not come with the game.

---

## What Imlight is

Imlight is server software. It takes the place of the original game servers, so a game client that you already own can connect to a server that you run yourself. It handles the parts of a server that an MMORPG needs: characters, moving through the world, mobs, inventory, chat, friends, combat and many more. The full list is further down on this page.

## What Imlight is not

Knowing the limits saves a lot of frustration. Imlight is **not**:

- **A finished game.** Do not expect a full game experience out of the box. It is a framework for building a private server.
- **A download that includes the game.** There is no client and there are no game assets in it. You must supply your own.
- **Complete.** Crafting, housing, pet minigames and multi-person mounts are not implemented yet.
- **A source of finished content.** Shops, quests, drops and parts of the world depend on SpiralDB data, and not all of that data has been collected. Some content can be empty or missing.
- **An official product.** It is an independent project. It is not made by the original game's developers.
- **A service you sign up for.** Imlight is software that you run. This guide shows how to host your own server and connect to it.

## Why it exists

The project started as a learning exercise. The goal was to explore how an MMORPG server works and how its architecture fits together. We have great respect for the original developers and that is why Revive101 does _not_ distribute any copyrighted game files.

- You need the original game client, and you must get it yourself.
- You also need any assets that the server uses, and you must get those yourself.

## Who is it for

Imlight is a good fit if you want to:

- run your own server and experiment with it
- learn how an MMORPG server is built
- help collect missing quest data or droptables
- contribute code.
