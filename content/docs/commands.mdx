# Using Commands

A number of commands are available for game masters.
Security tiers:

- `0`: Normal Player
- `1`: Quality Assurance
- `2`: Hall Monitors
- `3`: Developers (_only available in debug build_)
- `4`: Game Master

If Imlight was built in release mode, any command with a developer security level required will instead be forwarded to Game Master tier.

---

## Ungrouped Commands

| Syntax                | Security          | Example            | Description                                                                                                                     |
| --------------------- | ----------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------- |
| `.teleport $zoneName` | Quality Assurance | `.teleport wc_hub` | Teleports you to a specific zone. If a zone is not found, it will guess.<br/> A list of zones can be found [here](/docs/zones). |

## Context Commands

The commands below require a player to be selected to use.

> [!WARNING]
> Your command context will not drop. If you select a player, that player will still be in your context until you reconnect.

| Syntax                    | Security     | Example                            | Description                                             |
| ------------------------- | ------------ | ---------------------------------- | ------------------------------------------------------- |
| `.mute $duration $reason` | Hall Monitor | `.mute 4d20h3s what are you doing` | Mutes the entire account.                               |
| `.unmute`                 | Hall Monitor | `.unmute`                          | Unmutes the account.                                    |
| `.kick`                   | Hall Monitor | `.kick`                            | Kicks the player from the current server.               |
| `.warn $reason`           | Hall Monitor | `.warn tststs`                     | Adds an infraction record to the user's account.        |
| `.info`                   | Hall Monitor | `.info`                            | Shows account information about the selected character. |

## DynaMod Commands

| Syntax                           | Security          | Example                                                 | Description                                                                       |
| -------------------------------- | ----------------- | ------------------------------------------------------- | --------------------------------------------------------------------------------- |
| `.dynamod list`                  | Quality Assurance | `.dynamod list`                                         | Lists the dynamods on your character.                                             |
| `.dynamod set $state $clientTag` | Quality Assurance | `.dynamod set on WC_Rattlebones_ButterFlyZone instance` | Sets a dynamod to `on` or `off`. Creates it if it does not exist.                 |
| `.dynamod toggle $clientTag`     | Quality Assurance | `.dynamod toggle WC_Rattlebones_ButterFlyZone instance` | Toggles a dynamod between `on` and `off`. Creates it as off if it does not exist. |
| `.dynamod remove $clientTag`     | Quality Assurance | `.dynamod remove WC_Rattlebones_ButterFlyZone instance` | Removes a dynamod from your character.                                            |

> [!TIP]
> The `$clientTag` may contain spaces (e.g. `WC_Rattlebones_ButterFlyZone instance`), so it must always be the last argument. The tag must match the object's `m_zoneTag` exactly to affect it.

## Group Commands

These act on your own group, with your own rights: `kick`, `leader` and `disband` only work if you are the group leader. The client has no kick button for regular groups, so `.group kick` fills that gap.

| Syntax                   | Security          | Example                        | Description                                                             |
| ------------------------ | ----------------- | ------------------------------ | ----------------------------------------------------------------------- |
| `.group info`            | Quality Assurance | `.group info`                  | Lists your group's members with their leader flag, zone and sigil slot. |
| `.group kick $wizName`   | Quality Assurance | `.group kick Jake StarDust`    | Removes a member from your group. Alias: .group remove.                 |
| `.group leader $wizName` | Quality Assurance | `.group leader Dean WolfHeart` | Makes another member the group leader.                                  |
| `.group disband`         | Quality Assurance | `.group disband`               | Disbands your group.                                                    |

> [!TIP]
> `$wizName` is the member's full wizard name and may contain spaces, so it is always the last argument. It is _not_ case-sensitive.
