# Common Errors

This page covers common issues you may encounter when launching Revive101, connecting to an Aurorium instance, or synchronizing the SpiralDB repository.

## Failed to sync SpiralDB repository: repository path 'XYZ' is not owned by current user

This error occurs when Windows reports that the current user does not own the repository directory. Git uses ownership checks as a security measure to prevent potentially unsafe operations on repositories owned by other users.

1. Close Imlight.
2. Open File Explorer and navigate to the directory mentioned in the error message.
3. Right-click the directory and select **Properties**.
4. Open the **Security** tab and click **Advanced**.
5. Find the **Owner** field at the top and click **Change**.
6. Enter your current Windows username, click **Check Names**, and confirm with **OK**.
7. Enable **Replace owner on subcontainers and objects** to change ownership of the files and subdirectories as well.
8. Click **Apply** and confirm the changes.
9. Restart Imlight and try again.

## The client is Stuck on the 'HOLD ON' screen

- The client cannot establish a connection to the configured Aurorium instance.
- Aurorium is still starting or has encountered an error.
- The client is configured to use an incorrect server address or port.
- A firewall is blocking the connection.

**If you chose to host your own Aurorium instance,** it is probably not running. Start `aurorium.exe` inside the `Aurorium` folder and wait until it has finished starting. If you are not hosting your own Aurorium instance, make sure the public patch server `https://patcher.phill030.de` is reachable. If it is down, wait until it is back online.

## The client is stuck at 'Entering Game...'

Make sure you have the latest version of Wizard101. You may update the game by running the official launcher (`Wizard.exe`) after logging in, or by downloading the latest version from their official website.

## The server is stuck at 'Game server created with name...'

This means that you do not have the .NET Runtime 10 installed. You can install it from [**HERE**](https://builds.dotnet.microsoft.com/dotnet/Runtime/10.0.12/dotnet-runtime-10.0.12-win-x64.exe).

## I cannot connect from another computer

The address `127.0.0.1` always means the computer you are on. If the server runs on a different computer, the client cannot use it. You can either enable portforwarding in your router settings, or use programs like Hamachi or ZeroTier to let other people connect to your server.
